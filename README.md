# Tarot for KOReader

A Tarot and Lenormand plugin for KOReader.

Draw cards, reveal meanings, save reflections, and explore the cards directly on your device.

## Features

* Tarot and Lenormand support
* Daily Card
* Calendar with moon phases
* Hidden Card spread with a 5x4 grid
* Readings with up to  20 cards
* Physical Deck mode
* Card Book with meanings
* Use book highlights as personal card meanings
* Reflection Journal
* Adaptive fullscreen layout
* E-ink friendly refresh options
* Translations in English, Portuguese, Brazilian Portuguese,Spanish and Chinese

## Installation

Unzip and copy the plugin folder to:

```text
koreader/plugins/
```

Then restart KOReader and open the plugin from the tools menu.
