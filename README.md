# Arcana II — Tarot & Lenormand for KOReader

Explore Tarot, Lenormand, and your personal library directly on your e-reader.

Draw cards, discover their meanings, create readings, save reflections, and organize books about Tarot, astrology, occultism, spirituality, and much more — all within Arcana II.

## English

### Features

**Tarot & Lenormand**
- Support for Tarot and Lenormand decks.
- Daily Card with personal reflections.
- Customizable readings with up to 36 cards.
- Hidden Card spread with a 6×6 grid.
- Physical Deck mode.
- Card Guide with meanings and interpretations.
- Use book highlights as personal card meanings.
- Calendar with moon phases.
- Reflection Journal to save and organize your experiences.

**Personal Library**
- Add and read books about Tarot, astrology, occultism, spirituality, literature, and more without leaving Arcana II.
- Read books using KOReader's built-in reading engine.
- Organize books with collections, including smart collections.
- Search for book metadata and covers online.
- Rate books, save favorites, and filter your collection.
- Switch between list and bookshelf views.
- Return directly to the Arcana II Library after reading.

**Interface & Customization**
- Customizable home screen with swipe navigation between modules.
- Optional modules and personalized shortcuts.
- Expanded quick settings for device controls.
- PIN protection with a lock screen clock.
- Optional Super Maples font for selected interface elements.
- Adaptive fullscreen interface designed for e-ink screens.
- Optimized cover caching, navigation, and screen refreshing.
- Available in English, Portuguese, Brazilian Portuguese, Spanish, and Simplified Chinese.

### Installation

1. Download the latest Arcana II release.
2. Extract the ZIP file.
3. Copy the `tarot.koplugin` folder to `koreader/plugins/`.
4. Restart KOReader.
5. Open Arcana II from the Tools menu.

Existing users can update without intentionally deleting their personal data and settings. Backing up your files before updating is recommended.

## 简体中文

### 关于 Arcana II

Arcana II 是一款适用于 KOReader 的塔罗牌与雷诺曼卡插件，旨在让用户直接在电子阅读器上体验抽牌、解读、占卜与个人反思。

你可以抽取卡牌、查看牌义、进行牌阵占卜、记录心得，还可以整理与阅读塔罗牌、占星术、神秘学、灵性以及其他主题的书籍，无需离开 Arcana II。

### 主要功能

**塔罗牌与雷诺曼卡**
- 支持塔罗牌和雷诺曼卡牌组。
- 每日一牌与个人感悟记录。
- 可自定义牌阵，最多支持 36 张卡牌。
- 使用 6×6 网格的隐藏卡牌牌阵。
- 实体牌组模式。
- 牌卡图鉴，提供牌义与解读。
- 可以将书籍中的划线摘录用作个人牌义。
- 带有月相信息的日历。
- 反思日记，用于保存和整理个人体验。

**个人书库**
- 无需离开 Arcana II，即可添加和阅读有关塔罗牌、占星术、神秘学、灵性、文学及其他主题的书籍。
- 使用 KOReader 内置阅读器阅读书籍。
- 通过收藏集整理书籍，包括智能收藏集。
- 在线搜索书籍元数据和封面。
- 为书籍评分、添加收藏并使用筛选功能。
- 在列表视图和书架视图之间切换。
- 阅读结束后可直接返回 Arcana II 书库。

**界面与个性化设置**
- 可自定义主页，支持通过滑动手势切换模块。
- 可选模块与自定义快捷方式。
- 扩展快捷设置面板，方便控制设备功能。
- PIN 码保护与锁屏时钟。
- 部分界面元素可选用 Super Maples 字体。
- 专为电子墨水屏设计的自适应全屏界面。
- 优化封面缓存、页面导航和屏幕刷新。
- 支持英语、葡萄牙语、巴西葡萄牙语、西班牙语和简体中文。

### 安装方法

1. 下载最新版本的 Arcana II。
2. 解压 ZIP 文件。
3. 将 `tarot.koplugin` 文件夹复制到 `koreader/plugins/` 目录。
4. 重新启动 KOReader。
5. 从工具菜单中打开 Arcana II。

旧版本用户可以在不主动删除个人数据和设置的情况下进行更新。建议在更新前备份文件。
